# Privacy Policy - Respira

Ultimo aggiornamento: aprile 2026

## Raccolta dei dati
Respira non raccoglie, trasmette o condivide alcun dato personale.
L'app non richiede registrazione né connessione internet.

## Dati salvati localmente
L'unico dato salvato è lo storico delle sessioni di respirazione, 
conservato esclusivamente sul dispositivo dell'utente.

## Conservazione dei dati
I dati dello storico sessioni vengono conservati localmente 
sul dispositivo fino a quando l'utente non disinstalla l'app.

## Eliminazione dei dati
L'utente può eliminare tutti i dati in qualsiasi momento 
disinstallando l'app dal proprio dispositivo.
Nessun dato viene trasmesso a server esterni, quindi non è 
necessaria alcuna richiesta di cancellazione.
